# line-food-ordering-web

หน้าเว็บสำหรับระบบสั่งอาหารในกลุ่มไลน์ (โฮสต์ด้วย GitHub Pages) — ซอร์สและเอกสารอยู่ใน repo private `line-food-ordering`

- `order.html` — หน้าสั่งอาหาร เปิดผ่าน LIFF (ตั้งเป็น Endpoint URL ของ LIFF app)
- `dashboard.html` — แดชบอร์ดแอดมิน (ต้องใส่รหัส `ADMIN_KEY`) **อย่าส่งลิงก์นี้ในกลุ่ม**

สองไฟล์นี้เป็นสำเนาที่ใส่ URL ของ Apps Script Web app แล้ว (ค่า `API`) — ไม่มีความลับในไฟล์ ความลับทั้งหมดอยู่ใน Script Properties ของ Apps Script
อย่าแก้ไฟล์ตรงนี้ ให้แก้ที่ซอร์สใน repo หลักแล้วคัดลอกมา
